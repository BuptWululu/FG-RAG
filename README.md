## Usage

### Installation

```bash
conda create -n FG-RAG python=3.12.4 -y
conda activate FG-RAG
conda install -c conda-forge faiss-gpu -y
pip install llama_index==0.12.12
```

### Configuration

Before running, you need to change some configuration information for `Config.py` in the `Steps` directory. The specific meaning of each parameter is described in the notes in the document. We recommend not to modify the FG-RAG related configuration.

### Running

```bash
python Steps/RunFGRAG.py
```

### Evaluation

#### Dataset

The dataset used in FG-RAG can be downloaded from [TommyChien/UltraDomain](https://huggingface.co/datasets/TommyChien/UltraDomain). Additionally, it can also be found in the **Dataset** directory of the project.

#### Generate Query

We generated queries by referencing the code provided in [LightRAG](https://github.com/HKUDS/LightRAG) and made the Query-Focused Summarization queries used in the paper available in the **query** directories of each domain dataset. Additionally, the **output** directories for each domain dataset contain answers generated by FG-RAG when addressing these queries using four distinct models: gpt-4o-mini, qwen2.5-7B-instruct, qwen2.5-3B-instruct, and qwen2.5-1.5B-instruct.

#### Batch Evaluation

After modifying the path in the `RunEvaluate.py` file to the location of the two answer files to be compared, execute the following command:

```bash
python Steps/RunEvaluate.py
```
